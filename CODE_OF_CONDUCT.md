# Working together

Treat contributors with respect. Welcome questions, reproductions, translations, and small improvements.
Discuss the behavior or design with evidence, and explain how someone can improve a rejected proposal.
Do not harass, threaten, discriminate, disclose private information, or attack a person.

The repository maintainer handles reports and may ask for changes, hide content, or restrict participation.
Use a public Issue for ordinary collaboration concerns without naming private details.
For a concern requiring privacy, request a private contact first; use the Security tab only for vulnerabilities.
Maintainers apply these rules to repository discussions, Issues, and pull requests.
